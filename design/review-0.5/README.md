# Zephyr Extension 0.5.0 · 逐页设计对照

**简体中文** | [English](README.en.md)

本页保留 0.5.0 的历史验收。当前四入口纵向工作台见[逐项评审](../review/README.md)。


验收对象是独立扩展的 VSIX。在 Windows 的独立 VS Code 配置中打开安装版，同时在 Edge 打开原始 HTML。把 HTML 视口设为与编辑区相同的宽度，再比较标题、导航、分组和操作。截图均为 1920×1080；CSS 像素取决于显示缩放和侧栏宽度。

## 实测记录

- 在约 1178 CSS 像素宽的编辑区，逐页比较 HTML 与插件的计算样式。主标题约 35.35px、分组标题 16px、导航 15px。所抽查的字号、行高、左侧内边距差异均小于 0.1px。
- 对五页分别检查约 722、458、298 CSS 像素宽的编辑区。检测导航按钮、构建入口、标题栏、工具行和构建目标行的兄弟控件边界，未发现交叠或整页横向溢出。极窄宽度下可在导航自身横向滚动。
- 实测配置图 75%、100%、125%、150%、200%。以同一窗口的 100% 图宽为基准，实际宽度与显示比例的误差小于 1.5 个百分点。修正了原先放大到 200% 后，垂直滚动条导致图宽额外缩小的问题。
- 在 west 工作区和 CMake 两条路径，用 `mps2an386` 筛到 `mps2/an386`。在 CMake 测试应用中选择后，目标行显示完整限定名。west 工作区能找到使用 `tests.yaml` 的 `hello_world`。
- 在临时应用中把 `CONFIG_GPIO` 从 `y` 选为 `n`，检查暂存后磁盘仍为原值，点击「保存到工程」后才发生变化。真实 west 工作区只用于读取候选目标。
